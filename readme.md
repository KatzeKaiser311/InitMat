# InitMat

A Python tool for creating and editing initial soil particle distributions.

## Project Structure

```text
InitMat/
├── data/
├── output/
├── scripts/
├── src/
│   └── initmat/
├── visualizations/
├── README.md
├── requirements.txt
├── pyproject.toml
└── run.py
```

## Installation

Install InitMat and all required dependencies:

```bash
python -m pip install -r requirements.txt
```

## Run

Run the program from the project root directory:

```bash
python run.py
```
